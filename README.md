# Path of Building IA - installer

Download **[PathOfBuildingIA-Setup.exe](https://github.com/trubat-d/PathOfBuilding/raw/installer/PathOfBuildingIA-Setup.exe)** and run it.

- Installs per user (no administrator rights) in `%LOCALAPPDATA%\Programs\Path of Building IA`, with Start menu and desktop shortcuts.
- Separate from the official Path of Building: its own folder, builds and settings (kept in its folder).
- The first start downloads the program from this repository's `dev` branch (about 800 MB, a few minutes); every later start offers the new versions (Path of Building's own updater).
- Windows SmartScreen may warn the first time: "More info" -> "Run anyway".
- Uninstall from Windows' Apps list: builds, settings and what the generator learned stay in the folder.
